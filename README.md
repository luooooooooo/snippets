# 片段（Snippets）

![GitHub release (latest by date)](https://img.shields.io/github/v/release/kvelzer/snippets)

## 项目来源与关系

本项目是 [kvelzer/snippets](https://github.com/kvelzer/snippets) 的一个 **fork（分支修改版）**。

- **原项目（上游 / upstream）**：`https://github.com/kvelzer/snippets.git`，已配置为 `upstream` 远程源，用于持续追踪原作者的更新。
- **本仓库（origin）**：在本 fork 中进行的全部修改都提交并推送到你自己的远程仓库，与原项目保持「追踪但不自动合并」的关系——既能独立维护自己的改动，又不丢失与上游的可追溯关联。

本地仓库已配置好两个远程源，保持与原项目的关联：

```bash
# 查看远程源（应同时看到 origin 与 upstream）
git remote -v

# 拉取上游更新（仅获取，不会改动你的本地分支）
git fetch upstream

# 将上游更新合并 / 变基到本地主分支（按需执行）
git merge upstream/main      # 或：git rebase upstream/main

# 把本 fork 的改动推送到你自己的仓库
git push origin main
```

> 通过 `upstream` 追踪原项目、`origin` 托管自己的修改，即可在「同步上游」与「保留个人改动」之间灵活切换。

一个完全离线的小型 Android 应用，用于保存和编辑带格式的文本片段，并**保留格式**复制到剪贴板，从而可以带格式地粘贴到支持富文本的应用中。桌面小部件可一键复制某个片段。

- Kotlin，经典 Views + XML（未使用 Compose）
- 不申请任何权限——无网络、无数据统计
- minSdk 26，targetSdk 36，AGP 9.2.1，Gradle 9.6.1

## 构建

需要 JDK 17+ 以及 Android SDK（platform 36）。通过 `ANDROID_HOME` 环境变量，或项目根目录下的 `local.properties` 文件，把构建指向你的 SDK：

```properties
sdk.dir=/path/to/Android/Sdk
```

然后：

```bash
./gradlew assembleDebug
```

生成的 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。

## 安装到 USB 连接的手机

1. 手机上：设置 → 关于手机 → 连续点击**版本号** 7 次以开启开发者选项，然后在 设置 → 开发者选项 中开启 **USB 调试**。
2. 通过 USB 连接，在手机上确认「允许 USB 调试？」的提示。
3. 验证连接并安装：

```bash
adb devices          # 应列出你的手机，状态为 "device"
./gradlew installDebug
```

## 使用应用

- **+** 新建一个片段。编辑器是一个真正的 HTML 编辑界面（contenteditable 模式的 WebView）：无论你粘贴什么——表格、字体、字号、嵌套列表——都能正确渲染、保持可编辑，并以原样复制出去。工具栏包含 **粗** / **斜** / **下**、**色**（文字颜色）以及 **•≡** / **1≡**（项目符号 / 编号列表）；它们作用于当前选区，或从光标位置开始生效。
- 编辑器的 ⋮ 菜单中有 **编辑 HTML 源码**——可以在等宽编辑器中查看或手动修改片段的原始 HTML，然后切回可视化编辑器（或直接保存）。你输入的内容会被原样存储。
- 返回键自动保存（未改动的内容不会被触碰）；对勾图标用于显式保存。每一行列表上的垃圾桶图标（或编辑器 ⋮ 菜单）用于删除。
- **列表交互（手势操作）**：点按任意一行即把该片段**带格式复制到剪贴板**（含纯文本回退与原始 HTML）；**从左往右滑动**某一行进入编辑；**从右往左滑动**删除该行（会弹出确认）。
- 列表保留手动排序：长按并拖动某个片段来移动它；新建的片段会出现在顶部。列表界面的 ⋮ 菜单中有 **主题** 选择器（跟随系统 / 浅色 / 深色）。
- **标签排序**：标签栏支持多种排序方式——点 ⋮ 菜单中的 **排序方式** 图标，可选择「名称 A→Z」「名称 Z→A」「使用最多」「最近添加」。其中「使用最多」按标签被引用次数排序，「最近添加」按创建时间倒序排列。排序方式会被持久化保存。

## 模板

**模板** 标签页用于存放带一个可替换部分的片段：

1. 创建一个模板，写下文本，选中会变化的部分（一个名字、一个日期……），然后点 **{ }**——选中的部分会变成一个高亮的占位槽。
2. 在应用内填充：在工具栏上方的输入框中键入新值，然后点 **应用**——或者任意位置复制一个值，再点该模板列表行上的剪贴板图标，一次性完成填充并复制。模板会记住上一次的值。
3. 更快的做法：添加一个绑定到该模板的 **模板（从剪贴板填充）** 小部件。任意位置复制一个值（比如邮件里的一个名字），点一下小部件——该值会替换占位槽，剪贴板随即保存已填充、带格式的片段，随时可粘贴进 Gmail。

另外还有一个 **模板（原样复制）** 小部件：它一键复制该模板（使用上次保存的槽位值），不读取剪贴板、不做填充——适合反复复用同一个已填充的片段。它的行为与下面的片段一键复制小部件类似，只是绑定到模板。两种模板小部件在 1×1 尺寸时会缩小（隐藏标题），更宽时显示标题。

## 小部件：一键复制

1. 长按主屏幕 → 小部件 → **片段** → 把「片段（一键复制）」拖到主屏幕上。
2. 会打开一个选择器——选择该小部件要复制的片段。小部件会显示该片段的标题。
3. 点按小部件：片段会带格式被复制。Android 13+ 会显示系统的「已复制」浮层；更早的版本显示一个简短的提示。

如果绑定的片段被删除，小部件会切换到「片段已删除——点按重新配置」；点按它会重新打开片段选择器。

## 测试粘贴到 Gmail

1. 创建一个带混合格式的片段（加粗文字、彩色文字、下划线）。
2. 复制它——通过列表行上的复制图标或小部件。
3. 打开 Gmail → 写邮件 → 在正文长按 → **粘贴**。格式应当得以保留。（如果你选择「以纯文本粘贴」，格式会被有意丢弃——该选项读取的是剪贴板的纯文本表示。）

## 关键实现原理

- **编辑**：编辑器是一个 WebView，其页面（`assets/editor.html`）含一个 `contenteditable` 的 div——由真正的浏览器引擎直接编辑片段的 HTML，因此不会在转换为原生文本控件时丢失任何内容。页面在每次编辑时把 HTML 推送给 Kotlin，所以保存是同步的。格式按钮调用 `document.execCommand`。
- **持久化**：片段以 HTML 形式存储在单个 JSON 文件中（`NoteStore`），以原子方式写入。存储的 HTML 是唯一的真实来源——它绝不会经过 Android 有损的 `Html.toHtml` / `fromHtml` 转换器。
- **带格式复制**：`ClipData.newHtmlText(label, plainText, htmlText)` 把两种表示都放到剪贴板上（`ClipboardHelper`）——其中 HTML 直接来自存储，原样不动。富文本编辑器读取 HTML；纯文本输入框则回退到纯文本。
- **小部件点按**：Android 10+ 禁止后台代码写入剪贴板，因此小部件的 PendingIntent 会启动一个不可见的透明 Activity（`CopyNoteActivity`），在窗口获得焦点后再执行复制，随后结束。

## 本分支（fork）修改内容

在原项目基础上，本 fork 主要做了以下改动：

1. **全面中文化**：所有用户可见的界面文案、`arrays.xml` 与 `README.md` 翻译为简体中文（代码标识符保持英文，确保可编译）。
2. **列表交互改造**：移除列表行右侧的「克隆 / 复制 / 删除」三个按钮；改为**点按整行即复制**、**从左往右滑进入编辑**、**从右往左滑删除**（弹确认框），并移除了「克隆」功能。
3. **整体视觉焕新**：列表项改为 Material 3 卡片，统一蓝色主题色；滑动手势加入背景色 + 图标可视化（右滑绿底铅笔、左滑红底垃圾桶）；新增剪贴板空状态图标。
4. **多配色主题**：在原有的「跟随系统 / 浅色 / 深色」之外，新增「蓝 / 绿 / 紫 / 青 / 橙 / 粉」六套主色主题，可在 ⋮ 菜单中切换。
5. **标签分类功能**：
   - 列表顶部新增可左右滑动的标签栏（「全部」+ 各标签 + 「+」新建），支持多选筛选（命中任一标签即显示）。
   - 每条笔记可挂多个标签，在编辑器内勾选或新建。
   - 首页标签支持**长按**弹出菜单，可**重命名**或**删除**标签；重命名 / 删除会同步更新所有笔记的标签引用。
6. **复制提示修复**：点击复制后「已复制」Toast 在 Android 13+ 上也能正常显示。
7. **交互 bug 修复**：修复从右往左滑删除、点对话框外空白取消后卡片卡在半删除状态的问题。
8. **列表项留白优化**：多次迭代加大列表项文字与卡片背景之间的间距，最终文字到卡片边缘留白约 52dp，视觉更宽松。
9. **标签排序功能**：标签栏支持四种排序方式——按名称 A→Z（拼音）、名称 Z→A、使用最多（引用次数）、最近添加（创建时间倒序）。中文排序基于 `Collator.getInstance(Locale.CHINESE)` 实现拼音排序，更贴合中文用户预期。排序偏好通过 SharedPreferences 持久化保存。

> 以上改动均保留原项目的离线、无权限、HTML 原样存储等核心设计，未引入任何网络或数据统计行为。
